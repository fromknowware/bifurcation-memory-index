**Tier logic:**

●  **Manufacturers**  (Micron, Samsung, SK Hynix, CXMT)  — DRAM prices move here first; direct RI input.

●  **HBM Demand**  (Nvidia, TSMC, AMD)  — GPU allocation decisions set the HBM ceiling; drive R AI~.

●  **Downstream**  (Intel, Qualcomm, WD, Seagate)  — absorb RAM cost 1–2 quarters later; lag indicators.

When Tier 1 and Tier 2 diverge, the RI bifurcates.
